## QR contact

Le QR présent dans la fiche est un QR **vCard**.

Il permet d’enregistrer directement le contact MANÉ & GNING dans le téléphone avec :

- nom de l’agence
- métier
- zone
- numéros de téléphone

Le QR est intégré directement dans le HTML pour éviter :

- les chemins cassés
- les fichiers QR oubliés
- la dépendance à une API externe
- les problèmes de GitHub Pages avec un fichier séparé
